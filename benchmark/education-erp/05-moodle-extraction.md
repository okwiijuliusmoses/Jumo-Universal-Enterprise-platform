# Benchmark Extraction: Moodle LMS
## Level 1 — Product Identity
*   **Product Name:** Moodle LMS (Modular Object-Oriented Dynamic Learning Environment)
*   **Product Category:** Learning Management System (LMS)
*   **Target Market:** Higher Education, Schools, Corporate Training Programs.
*   **Target Users:** Lecturers, Teachers, Instructional Designers, Corporate Trainers, and Students.
*   **Deployment Model:** Self-Hosted Open-Source, Cloud SaaS (MoodleCloud), or Hybrid.
*   **API/Developer Surfaces:** Extensive REST Web Services, LTI 1.3 compliance, custom plugin modules architecture.

---

## Level 2 — Organizational Structure & Offices
*   **Instructional Design Team:** Authors course syllabi, constructs learning modules, and uploads educational media.
*   **Exam Moderation Board:** Evaluates quiz pools, grading rubrics, and final exams.
*   **IT System Administration:** Handles user enrollment syncs, plugin installations, and server scaling.

---

## Level 3 — Core Functional Modules
*   **Course Creator:** Handles hierarchical topic layouts, video uploads, and assignments.
*   **Quiz and Assessment Engine:** High-capacity quiz platform supporting multiple choice, essays, drag-and-drop, and adaptive questions.
*   **Moodle Gradebook:** Complex weighted grade manager supporting custom scales, letter grades, and grade overrides.
*   **Activity Completion Tracker:** Restricts subsequent modules based on pre-requisite completion.

---

## Level 4 — Portals and Access Levels
*   **Student Dashboard:** Calendar events, assignment submission status, course catalogs, and grade tracker.
*   **Lecturer Workspace:** Course editing, grading dashboards, student activity reports, and forum discussions.
*   **Site Admin Console:** Server configurations, database backups, user profile mappings, and integrations.

---

## Level 5 — Core Business Workflows
1.  **Student Assignment Submission and Grading:**
    *   *Trigger:* Student uploads PDF assignment.
    *   *Validation:* Runs plagiarism check (if integrated).
    *   *Grading:* Lecturer receives notice, grades via rubric, and submits comments.
    *   *Posting:* Gradebook updates and triggers a notification to student.
2.  **Course Completion Certification:**
    *   *Trigger:* Student completes all required activities.
    *   *Result:* System auto-generates custom PDF Certificate of Completion.
