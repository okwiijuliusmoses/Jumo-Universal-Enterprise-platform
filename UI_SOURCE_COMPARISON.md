# UI SOURCE COMPARISON

Comparing mature ERP interfaces to define the Jumo User Experience.

| Feature | Odoo (Community) | ERPNext (Desk) | Aureus ERP (Filament) | Jumo Target |
| :--- | :--- | :--- | :--- | :--- |
| **Layout** | Icon-grid / Apps list. | Sidebar + Search-first. | Sidebar + Bento Cards. | **Aureus Pattern**: Modern, dense, sidebar-driven with high information density. |
| **Forms** | Multi-tab / Wizards. | Single-scroll / Sections. | Modular sections. | **ERPNext Style**: Fast, single-scroll forms with clear section dividers. |
| **Charts** | Integrated BI. | Custom Dashboard blocks. | Interactive widgets. | **Jumo-Native**: Recharts/D3 widgets embedded in responsive bento-grids. |

## Jumo UI Strategy
Jumo will reproduce the **"Command Palette"** and **"Workspace"** concepts from ERPNext/Frappe. Users should be able to navigate the entire ERP using only the keyboard, making it a "Power User" platform.
