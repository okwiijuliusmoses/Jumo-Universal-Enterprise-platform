# THIRD PARTY LICENSES

This document lists the third-party open-source projects that Jumo Universal Enterprise Platform references, adapts, or integrates.

## 1. Direct Dependencies (per package.json)
- **Express**: MIT
- **React**: MIT
- **Lucide React**: ISC
- **Framer Motion**: MIT
- **Firebase SDK**: Apache 2.0
- **Postgres (pg)**: MIT
- **OpenAI / Google GenAI**: Apache 2.0 / MIT

## 2. Architectural References (Non-Source Copy)
The following projects serve as functional benchmarks for Jumo's universal primitives:
- **ERPNext (GPLv3)**: Reference for Double-Entry Ledger and Chart of Accounts hierarchy.
- **Kill Bill (Apache 2.0)**: Reference for Subscription Billing and Open-Item management.
- **Hyperswitch (Apache 2.0)**: Reference for Payment Orchestration and Connector patterns.

## 3. Attribution Required
*No external source code has been directly forked into the core repository yet. All core primitives are independently implemented based on public specifications.*
